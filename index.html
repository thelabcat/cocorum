Cocorum: Rumble Live Stream API Python Wrapper

A Python wrapper for the Rumble Live Stream API v1.0 (beta), with some quality of life additions, such as:

  • Automatic refresh when past the refresh_rate delay when querying any non_static property.
  • All timespamps are parsed to seconds since Epoch, UTC timezone.
  • Chat has new_messages and new_rants properties that return only messages and rants since the last time they were read.

Rumble Terms of Service status

As for cocorum toplevel module, cocorum.static, and most of cocorum.utils, Rumble's Live Stream API help page says that, for now, users have "full reign" on using and implementing the Rumble Live Stream API however they want. However, Rumble's Terms of Service prohibit "any form of automated software to interact with or access the Rumble Site ... without the prior written permission of Rumble." They prohibit "systematic retrieval of data or Content ... to create or compile ... a collection, compilation, library, database or directory." They also prohibit harvesting information about chat and forum users. The network functions in cocorum.utils and the entirety of the rest of the library fit this description. I just discovered this recently, so shortly after publishing this update, I will be requesting said written permission, and will update the library according to their reply.

Even if Rumble says yes...

  • Use this library only on your own account or channel, or on streams you moderate.
  • Do not try to bypass any form of rate limits that Rumble may impose. This library is not intended to be used to harm Rumble or its users.
  • Do not use any of the features for bulk collection of data.
  • If Rumble asks you to stop, do.
